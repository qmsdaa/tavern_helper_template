# UI重做与选角修复

本轮沿用粉蓝色调，统一纸白底、墨蓝正文、44px普通操作和48px主要操作。主菜单使用图标网格，手机顶部整合收起和关闭按钮；桌面保留消息、联系人、地图、论坛、照片墙、购物、图廊、委托、日志、日程、状态、设置12项实际功能。

论坛按作者、标题、正文和回复排列；购物提供商品与订单切换，8件现有商品加入SVG图形；委托按状态排列，日志按时间线排列。正文与操作文字不小于16px，手机字号继续支持16—24px。

横屏的选角详情、设置、菜单、图廊及手机应用都有明确的滚动区域和可见滚动条。选角库与详情分别滚动，手机横向桌面采用人物日期栏和应用网格。

主界面与手机共用BGM播放器。播放方式为单曲循环、列表循环和随机播放；列表在末尾回到第一首，随机排除当前曲目。调整音量与播放方式不会从头播放当前曲目，选择的播放方式保存在本机。

选角会话校验增加首次进入时的锚点初始化，并识别同一角色、同一原生消息数组和同一回复下的聊天文件名更新。真正切到其他聊天、替换消息数组或改变当前回复时仍会拒绝旧界面的操作。进入操作在异步初始化之前锁定，防止重复点击。

自动检查278项通过；最终针对性复查82项通过，属于前述检查的子集。浏览器检查覆盖390×844、844×390以及选角、主菜单、设置、购物和手机桌面。音乐验证包括实际播放、原生loop属性、模拟ended事件后的列表与随机换曲及状态保存。本轮没有发送真实模型请求；选角开场完成由预览与宿主协议回归验证，未重新生成用户现有聊天。
