# 首次导入

1. 先导入`worldbook/黑长直综漫卡.json`，再导入PNG或JSON角色卡，二者任选一种。
2. 启用酒馆助手、提示词模板、卡内正则和两条角色脚本。本机验证版本为SillyTavern 1.17.0、酒馆助手4.11.0、提示词模板1.17.8.1。
3. 酒馆助手渲染深度至少2。提示词模板总开关、生成处理和生成加载器均开启。关闭助手的“强制使用推荐的世界书全局设置”，世界书上下文50%、Token上限18000、扫描深度2、“包括名称”开启、递归扫描关闭。
4. 从“新的游戏”选择自建或已有角色。更新旧卡时选择更新原卡，保留现有聊天关联，并覆盖同名世界书。
5. 手机、地图、日志和BGM开关都在菜单中。独立API在手机的“适配”或“设置→API连接”填写地址、模型和Key；本轮用DeepSeek验证。BGM默认关闭，开屏期间暂停背景音乐。

图片、建筑图集、音乐和脚本从固定云端版本按需读取。人物Q版等待用户的dot制作，当前地图先显示姓名标记。照片原件与API连接资料保存在本机。
