# 首次导入

1. 先导入`worldbook/黑长直综漫卡.json`，再导入PNG或JSON其中一种。
2. 启用酒馆助手、提示词模板、卡内文本过滤正则和两条角色脚本。主舞台由助手脚本常驻挂载，不依赖消息正则或渲染深度。
3. 提示词模板总开关、生成处理和生成加载器开启；关闭助手的“强制使用推荐的世界书全局设置”，世界书上下文50%、Token上限18000、扫描深度2、“包括名称”开启、递归扫描关闭。
4. 重新打开当前聊天会自动进入舞台。从“新的游戏”选择自建或已有角色；菜单可收起界面，右下角“打开界面”回到原舞台。更新旧卡时更新原角色，保留现有聊天关联。
5. 手机、地图、日志和设置在菜单内。手机保留12项现有功能；独立API在手机设置的“API连接”填写地址、模型和Key。BGM提供单曲循环、列表循环、随机播放，开屏期间暂停背景音乐。

140人Q版已按用户Dot原图接入，只显示已认识、地点明确且满足可见资格的人物。资源从固定云端版本按需读取；照片原件、连接Key与聊天保存在本机。本轮未调用模型。
