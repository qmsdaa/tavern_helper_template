# 初始数值与移动端测试版

本轮增加人物数值、原作通讯关系、CG占位解锁，以及移动端和选角修复。

140位可扮演人物与自建角色均有初值。六维为学力、知性、判断力、身体能力、协调性、精神力，范围0—100。成绩包括国语、数学、英语、理科、社会和自动计算的平均分。金钱按日元记录现金、存款、月收入、月零用。数值依据原作表现与本卡校园设定编制，属于游戏初值。

选择已有角色时，只建立该人物原有的联系人与所属群聊。全表含186条联系人关系和26个群，按角色分别初始化，不会把全表塞进同一部手机。自建学生从教师介绍入口开始，先取得平冢静的联络方式。初始会话没有伪造的聊天记录。庚夕子没有普通手机通讯录。

数值变化需要当轮正文经历与履历依据，现金同时同步到玩家钱包。旧存档缺少的新字段会补上初值，已经保存的数值保留。主线上下文继续按需投影，只提供当前玩家与最多两位在场人物的相关数值，其他人物的金钱不送入主线。变量投影继续采用原有3200字符上限。

CG本轮保留65个位置，不发布CG图片，不调用CG判定模型。每格可查看条件，支持单张或全部提前解锁。提前解锁保存在本浏览器的当前存档范围，不改变剧情、关系和实际事件；用户提交人工筛选图片后，再接入正式画面。

“继续生成”固定在对话区底部，竖屏、横屏均保留空间。提示词长度计算的空跑事件不会把按钮锁定为生成中。顶部“原生聊天”收起舞台并定位原生输入框；“返回界面”回到同一个舞台。“新对话”进入现有的新游戏流程。选角入口统一识别首条创建标记、尾部空行与状态占位符。

本版不更换人物美术与Q版，手机维持现有功能。验证使用自动检查与本地浏览器，不发起真实模型续写。
