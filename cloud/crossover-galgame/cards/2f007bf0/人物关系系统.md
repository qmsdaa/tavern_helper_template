# 人物关系系统

亲近 `bond` 和爱恋 `romance` 沿用原卡，均为0~100。亲近记录熟悉、信任与亲密，爱恋记录恋爱倾向。新增认可 `recognition`（0~100），记录人物对玩家能力、处事方式和价值观的评价，`recognition_basis` 保存具体依据。三者独立：可以认可一个疏远的竞争者，也可以亲近一个在某件事上意见不同的人。

旧档不推算认可。缺少新字段时由Schema补0和空依据，界面显示“未评价”；已有双维数值及承诺原样保留。有评价且降至0时显示0。

`commitment` 继续保存未确认／仅朋友／恋人；恋人的双心徽章只从该字段及其依据派生。`special_relations` 为按关系名组织的动态记录，每项保存 `basis` 和故事日期 `since`。新增与删除均由实际剧情决定，界面不根据数值授予关系。

| 关系 | 图形 | 成立情形 |
| --- | --- | --- |
| 恋人 | 双心 | 双方明确交往 |
| 挚友 | 双星 | 长期互信与支持 |
| 闺蜜 | 缎带 | 双方成立的亲密友谊 |
| 知己 | 相接气泡 | 理解彼此隐秘想法 |
| 搭档 | 拼图 | 持续合作并互相配合 |
| 竞争对手 | 双旗 | 争取同一目标 |
| 宿敌 | 交叉剑 | 长期较量 |
| 死敌 | 荆棘盾 | 重大冲突形成持续敌意 |
| 冷战 | 雪花 | 争执后暂时疏离 |
| 前任 | 碎心 | 已结束的恋情 |
| 家人 | 屋檐与心 | 实际亲属或共同认可的家人关系 |

例如恋人可同时是知己或搭档，挚友也可长期互相较量。和好后解除冷战，分手后更新承诺并记录前任，已经结束的关系应删除。其他有依据的关系名可以继续记录，显示通用绶章。

人物详情显示完整徽章和三维数值。状态栏与地图人物列表显示前两个徽章，顺序为恋人、家人、挚友、闺蜜、知己、搭档、竞争对手、宿敌、死敌、冷战、前任；点击人物可看完整资料。只展示原可见性规则允许的已认识人物；不为未遇见人物批量建立记录。

变量更新规则随当前卡发布；按需剧情投影仍只发送当前相关人物，不因增加关系维度加载全员资料。所有徽章用SVG绘制，无新增图片或模型调用。
