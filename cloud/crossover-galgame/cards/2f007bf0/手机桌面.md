# 手机桌面

手机沿用用户提供的参考布局：浅色硬件状态栏、黑色灵动岛、暮色渐变壁纸、四列彩色实心图标、底部快捷栏。日期、时间、地点及当前时间节点来自当前存档，未使用参考图的2013年日期。常规视口按504∶1075的机身比例适配，四行图标下方保留留白，Dock固定底部；文字最小16px。主页场景编号按已提交助手日志中的日期和地点切换派生，只用于展示。

| 第一页 | 用途 |
| --- | --- |
| 消息、好友、档案 | 现有会话、真实联系人与已认识人物资料；三维关系和特殊关系徽章保留 |
| 状态、物品 | 已知在场人物、现金、随身物品与数量；物品页可进入购物 |
| 章节、纪要、日记 | 当前时间节点、玩家可见手机消息摘要、现有楼层日志 |
| 适配、设置 | 独立API连接、阅读主题和BGM |
| 地图、CG、论坛、委托 | 已有地图行踪、已解锁CG、论坛和奉仕部委托 |
| 备忘、壁纸 | 当前会话和身份专属的本机备忘，以及暮色、樱夜、深海、星夜四种渐变壁纸 |

照片墙、购物、图廊、日程保留在第二页。底部四个快捷入口为消息、状态、地图、设置；分页圆点和横向触摸滑动均可切换桌面。返回条与应用左上返回键可回到桌面。浮窗保留拖动、收起和关闭。

备忘与壁纸写入按会话、开局和玩家身份隔离的localStorage；不进入MVU、剧情正文或模型提示词。备忘只有存储成功后清空输入。API凭据仍沿用原有本机存储规则，不随这轮界面改动迁移。

手机内地图复用原建筑图集与可见性规则；嵌套地图SVG不受普通24px图标样式影响。父级悬浮界面的素材路径优先取角色卡中固定版本的云端资源目录，避免iframe丢失base标签后请求酒馆根目录。

本轮不新增美术、音乐或MV资源，不修改MVU字段和世界书剧情，不调用真实模型。现有独立API功能沿用前轮验证，不再发起模型烟测。
