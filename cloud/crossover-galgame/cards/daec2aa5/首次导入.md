# 首次导入

1. 在SillyTavern启用酒馆助手和提示词模板插件。
2. 先导入worldbook目录中的“黑长直综漫卡.json”，保留这个世界书名。更新旧版本时，更新同名世界书。
3. 导入“黑长直综漫卡.png”，或使用JSON格式角色卡，任选一种。
4. 启用卡内正则与两条角色脚本，启用提示词模板的生成处理和生成加载器。
5. 从标题选择新的游戏，使用自建角色或已有角色开始。

世界书预算沿已验收设置：关闭酒馆助手“强制使用推荐的世界书全局设置”，上下文百分比50%、预算上限18000、扫描深度2、包括名称开启、递归扫描关闭。酒馆助手渲染深度至少2。

开场播放《阿尔吉侬》MV，可以暂停或跳过。图片、前端和运行代码从固定云端版本读取；聊天、关系、手机与存档保存在本地酒馆。模型使用自己的酒馆连接设置。

时间由玩家选择推进；当前时间与地点符合条件时，读完回复可进入可选短场景，也可继续自由输入。麻衣图书馆入口保存本人介绍与当次见闻，是否帮忙仍由玩家决定。
