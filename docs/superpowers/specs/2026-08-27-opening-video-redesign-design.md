# 《Counterfeit》开场白视频化重构 · 设计文档

日期：2026-08-27
状态：已确认（分镜/素材/前端三段均已逐项过审）

## 背景

现有开场白序奏（`src/Counterfeit/界面/开场白/IntroSequence.vue` + `introAssets.ts`）为静态 CG + 代码运镜（8 帧定义，4 张 CG：intro_group / intro_trauma / intro_token / intro_selfie）。本次重构用 Seedance 图生视频替换序奏，并对标题屏背景做动态化。

## 范围

- ✅ 序奏（启动门之后、标题屏之前的 OP 式过场）→ 视频化
- ✅ 标题屏樱花背景 → 动态循环视频
- ❌ 画廊、POV 视角卡、cover.webp 封面、DLC 入口：不动
- ❌ BGM 机制（audio.ts、启动门解锁）：不动，仅重新剪辑对齐 30s

## 关键决策

| 决策点 | 结论 |
|---|---|
| 画幅 | 单版本 16:9（1080p 直出；竖屏设备 `object-fit: cover` 居中裁切，已告知用户并接受） |
| 叙事概念 | 四季流转·一年时间线（编年体式六拍），锚定 150 场主线剧情节点 |
| 时长 | 约 60s = 6 拍 × 10s；拍间叠化 400ms |
| 首帧 | 全部新生成（7 张：6 拍 + 标题屏），画风以画廊现有场景 CG 为基准 |
| 分辨率 | Seedance 直出 1080p，无需超分 |
| 转场 | 单首帧生成 + CSS 叠化，不用首尾帧模式 |
| 信物 | 烧焦丝带作为特写道具仅出现在拍 4/5；拍 2/3/6 中拉芙腕上的丝带是角色固有外观，不算特写镜头，规避道具一致性风险 |

## 前端改造

改动范围全部在 `src/Counterfeit/界面/开场白/`：

1. **新增 `introVideos.ts`**：6 拍播放清单（10s/拍、单 16:9 源、字幕文案、日期标注），替代废弃的 `introAssets.ts`（删除）。
2. **重写 `IntroSequence.vue`**：双 `<video>` 元素交替播放，`ended` 事件驱动切拍，CSS 交叉叠化 400ms；字幕层左下角手写体日期行随拍切换；`object-fit: cover` 满屏；右下角常驻跳过按钮（保留现有行为）。
3. **画幅**：单 16:9 源，所有设备 `object-fit: cover` 满屏，竖屏设备只显示画面中央 1/3 宽度。序奏开始时不再选源，中途不随旋转切换。
4. **加载策略**：GateScreen 等待点击期间预载拍 1 + 标题屏循环（`preload="auto"`），播放中后台预取下一条。
5. **降级链**：单条视频加载失败 → 该拍首帧静态图（兼作 poster）代替；全部失败 → 跳过序奏直接进标题屏。序奏必须永远播得完。
6. **收束**：拍 6 结束 → 白场闪切（复用现有白幕收束 CSS）→ 标题屏。
7. **标题屏**：`TitleScreen.vue` 的 `bg_sakura.webp` 静态 `<img>` 换成 `<video loop muted autoplay playsinline>`，静态图作 poster 兜底；cover、按钮区、进入逻辑不动。

零改动：画廊、POV、copy.yaml、audio.ts、store.ts 流程（序奏结束/跳过 → 标题屏的既有跳转不变）。

## 测试

构建后验证：

- 桌面（横版源）+ 手机模拟器（竖版源）各跑完整流程：启动门 → 六拍 → 白场 → 标题屏循环 → 模式选择
- 断网/改文件名模拟视频 404，验证降级链（单条失败出静态图、全部失败直进标题屏）
- 标题屏循环无缝（首尾帧对齐）、无音频串轨
- 拍 6 → 标题屏的樱花树构图衔接自然
