# 移动端立绘居中与头像浅色放大层设计

## 背景

《错位的日常》开场白角色选择页在宽度不超过 520px 时由双列切换为单列，但角色卡内部的图片区没有单独的窄屏宽度、缩放和居中约束，导致立绘视觉上聚集在卡片左侧。对话渲染插件的头像放大层当前使用深黑遮罩、深色图片底色和 `object-fit: cover`，透明 WebP 在放大时会呈现黑底，并可能被裁切。

## 目标

- 桌面端角色选择双列布局保持不变。
- 520px 及以下的单列角色卡中，图片区占满卡片宽度，立绘稳定水平居中。
- 立绘按可用宽度自适应，既不溢出也不因固定高度显得过小。
- 性转八幡及其他透明头像放大后使用浅灰／暖米白展示卡，不再出现黑底。
- 放大图完整显示，不裁掉透明头像的边缘或主体。
- 保留点击空白处与按 Esc 关闭预览的交互。

## 采用方案

采用局部响应式修复，不重新处理或覆盖立绘素材。

### 开场白角色卡

- 保留 `.dlc-pov-grid` 在桌面端的双列结构和 520px 以下的单列结构。
- 明确 `.dlc-pov-card` 与 `.pov-art` 的可用宽度约束，避免 flex/grid 子项按内容宽度收缩。
- `.pov-art` 在移动端占满角色卡内容宽度，并继续使用 flex 居中。
- 图片以 `max-width: 100%`、自动宽度和基于视口的受限高度展示；通过 `margin-inline: auto` 和居中定位形成多重保障。
- 图片继续使用 `object-fit: contain`，保持全身立绘比例；角色卡角标与选中标记的定位不变。
- 自建角色卡的加号图片区沿用同一尺寸与居中规则。

### 对话头像放大层

- 外层遮罩从深黑改为低透明度暖灰，并使用轻度 `backdrop-filter: blur(...)`，使页面仍有层次但不压暗画面。
- 图片外增加浅灰／暖米白展示卡视觉：圆角、细边框和柔和阴影。
- 图片背景使用固定浅色，不依赖当前对话主题变量，因此暗夜主题下也不会回落成深色。
- 放大图片从固定 `aspect-ratio: 9 / 13` + `object-fit: cover` 改为受视口约束的自然比例 + `object-fit: contain`，保证透明头像完整显示。
- 标题和关闭提示改为深灰／豆沙色，确保浅色遮罩上的文字对比度。
- 无头像时的首字占位也使用同一浅色展示卡。

## 影响范围

- `tavern_helper_template/src/Counterfeit/界面/开场白/DlcSetup.vue`
- `角色卡工程/脚本/对话渲染.js`
- 与上述源文件对应的镜像、打包产物或独立 JSON，按项目现有同步脚本更新。

不修改人物素材文件，不改变角色选择逻辑、对话解析逻辑、头像映射或本地存储格式。

## 验证

- 在 390px、430px、520px 宽度检查单列角色卡：图片区铺满、人物居中、无横向溢出。
- 在桌面宽度检查双列布局未回归。
- 分别放大性转八幡透明头像和至少一个普通头像：背景为浅灰／暖米白、主体完整、无黑底、无裁切。
- 在羊皮纸、暗夜、豆沙绿三种主题下重复放大检查，展示卡颜色保持一致。
- 验证点击遮罩和 Esc 均可关闭，重复打开不会残留多个浮层。
- 运行开场白构建与对话渲染无头测试，并按现有打包流程同步发布产物。

## 回退

所有改动均为局部 CSS 和放大层展示结构调整。若移动端出现兼容问题，可分别回退新增的窄屏样式和浅色放大层样式，不影响数据与素材。
